1. masuk.js
   Memvalidasi username dan password, mengenali role menggunakan if...else, lalu mengarahkan ke dashboard.
2. daftar.js
   Memvalidasi formulir registrasi, memeriksa kesamaan password, dan menampilkan modal pendaftaran berhasil.
3. sesi.js
   Mengelola sesi login, menyimpan informasi pengguna yang sedang login, dan memeriksa role.
4. keluar.js
   Menangani logout, menghapus sesi login, kemudian mengarahkan pengguna ke halaman login.

Halaman kebijakan_privasi.html dan syarat_ketentuan.html juga tidak membutuhkan JavaScript khusus karena keduanya merupakan halaman informasi statis.
